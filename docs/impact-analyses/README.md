# Historical impact analyses

This directory preserves the reviewed reasoning behind contract and behavior
changes. These records are an audit trail, not descriptions of the current
runtime architecture. Current responsibilities and constraints are defined by
`ARCHITECTURE.md`, `INTERFACE_CONTRACTS.md` and the component guides under
`docs/`.

New contract changes require a proportional impact analysis as defined in
`INTERFACE_CONTRACTS.md`. Historical branch names, release candidates and
comparison windows in these records must not be copied into production code or
current architecture documentation.
